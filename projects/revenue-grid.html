Overview

Revenue Grid is an AI-powered revenue intelligence platform that integrates with Outlook, Gmail, and Salesforce to help sales teams capture activity data and improve pipeline visibility. I joined as a Senior QA Engineer responsible for building and maintaining the entire quality assurance infrastructure across web, desktop, and email add-on products.

What I Did

  • Performed manual and automated testing for web and desktop applications, including Outlook and Gmail add-on extensions, covering functional, regression, smoke, E2E, and performance testing.
  • Designed, developed, and maintained a robust automation framework using Selenium WebDriver, C#, and NUnit, implementing the Page Object Model (POM) pattern to maximize script maintainability and scalability.
  • Managed and optimized an automated test infrastructure of 500+ tests across 5+ active C# projects, using TeamCity admin tools to build and maintain Smoke and Regression execution plans for CI/CD pipelines.
  • Conducted API testing with Postman, validating RESTful services (GET, POST, PUT, DELETE) and leveraging Selenium WebDriver locators — ID, Name, Class, XPath, and CSS Selectors — for precise UI element interaction.
  • Created and executed test cases for functional, positive/negative, GUI, and UAT scenarios, ensuring thorough coverage across all product areas.
  • Performed performance testing to assess system stability, identify bottlenecks, and optimize application responsiveness under load.
  • Collaborated closely with development teams to update test cases, resolve issues, and maintain robust test scripts.
  • Logged, tracked, and managed defects in JIRA, driving timely resolutions and effective communication across teams.
